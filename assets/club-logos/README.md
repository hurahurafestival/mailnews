# Logo klub Mailnews

Logo SVG yang ditampilkan di direktori klub disimpan lokal di folder ini agar halaman tidak bergantung pada hotlink untuk klub-klub tersebut.

Sumber koleksi: [JoseArroyave/football-logos](https://github.com/JoseArroyave/football-logos), dengan atribusi kepada repositori tersebut. Logo tambahan untuk klub yang tampil dinamis pada jadwal atau klasemen tetapi belum disalin lokal masih memakai URL raw dari sumber yang sama.

Koleksi sumber menyatakan penggunaan repositori gratis untuk proyek personal dan komersial serta menyediakan lisensi MIT untuk materi repositorinya. **Lisensi MIT tidak memindahkan kepemilikan merek dagang atau hak atas lambang klub**. Lambang tetap milik klub/federasi masing-masing; Mailnews menggunakannya untuk identifikasi dan informasi sepak bola. Periksa izin pemegang hak untuk penggunaan di luar konteks editorial/informasi.

Logo lokal yang saat ini dipakai: Persib Bandung, Persija Jakarta, Arema FC, Persebaya Surabaya, Bali United, PSM Makassar, Borneo FC, Dewa United, Manchester City, Manchester United, Arsenal, Chelsea, Real Madrid, Barcelona, Atlético Madrid, Sevilla, Inter Milan, Juventus, Napoli, Bayern München, Borussia Dortmund, Bayer Leverkusen, dan RB Leipzig.
